1. The question

TRINITY's 1-D interface cooling fraction θ undershoots the value Lancaster 2021b measures in 3-D, so realistic giant molecular clouds never fire the energy→momentum trigger. Three knobs can supply the missing cooling. Choosing between them is a calibration question: for each knob, what dose brings Θcum into the observed band [0.90, 0.99], and how much does that dose vary across cloud density? The knob whose calibrated dose varies least is the better single physical constant.

3. Is Θcum even the right metric? — no, and it changes the f_A verdict

TRINITY's trigger has no memory. run_energy_implicit_phase.py:1250 fires on (L_gain − L_loss)/L_gain ≤ 0.05, i.e. θ ≥ 0.95, evaluated per step on the current state. A cloud fires the instant θ first crosses the threshold, so θmax ≥ 0.95 is exactly "this cloud fires". Θcum is a different object — the Lmech-weighted mean of θ over the whole window.

Θcum is not a mistake — it is a mismatch. Lancaster 2021b measures a cumulative radiated fraction, so reproducing L21b genuinely requires an integrated quantity, and §15h adopted it correctly for that. The error was carrying a Lancaster-comparison metric into a knob-selection decision. The workstream's own 📏 rule 3 already says θ is reported as θmax; the band-entry calibration drifted off it and nobody re-checked whether the ranking survived the swap.

On the criterion the code actually uses, f_A and f_mix first came out TIED — 2.71× vs 2.64×, a 3% difference. f_A's 2× disadvantage in §2 is an artifact of the metric, and "f_mix beats f_A" must not be quoted as a physical result. Note also that the absolute doses differ ~4× (f_mix 3–8, f_A 11–31) while the spreads match.

Then the stale-row exclusion broke the tie — toward f_A (FINDINGS §12). On no-root β–δ segments the solver leaves Lcool frozen while Lmech keeps evolving, so θ can drift up on rows the solver never actually solved; 76/291 arms have their θmax set on such a row. Recomputing θmax over solved rows only: f_A's entries barely move (spread 2.71×, unchanged) but f_mix's bench1 entry slides 7.93 → 11.11 (fm=8's solved-row max is 0.927 < 0.95), degrading its spread 2.64 → 3.70×. f_A is now the most uniform knob outright — and it agrees with §4's mechanism ranking (f_A is in-solve; f_mix is a scalar on the answer).

f_κ loses on both metrics, and worse on this one — it never reaches θ = 0.95 on bench1 at any dose ≤ 32. §2's closure of f_κ is strengthened, not weakened. This metric is also far less exposed to §1's truncation problem: θmax is a maximum over whatever ran, and the f_A and f_mix trigger tracks contain zero truncated arms. Full treatment: FINDINGS §11–§12; per-arm columns (thetamax_row_stale, theta_max_solved) in pdv-trigger/data/bench_stale_segments.csv.

4. The mechanism check — none of the three is the wrinkled-interface knob

The Θcum calibration above scores only the radiative bookkeeping. The physical motivation for all three knobs is that turbulent mixing wrinkles the contact discontinuity, so its true area exceeds the 1-D spherical area. In the thin-layer limit that raises every interface flux together — conduction, radiation, and the evaporative mass flux. So an area-faithful knob has an unambiguous signature: Ṁ must RISE with dose.

knobwhere it actsstructure responds?Ṁ(f)/Ṁ(1)vs the wrinkle picture
f_mixL_leak + f·L_cool on the integrated output, feeding the energy equationno — structure-frozen, energetics-live≡ 1 ❌ no mass-loading response at all
f_Adudt = f·dudt inside the ODE, interface band only yes (radiative source)0.988 → 0.855 ❌ wrong sign — cooler interface evaporates less
f_κC_thermal — the Spitzer conduction coefficient yes (transport)1.07 → 0.94 → 0.29 ⚠️ right sign only below f_κ ≈ 7

In the dose range where any of these would actually be calibrated, not one raises mass loading. f_κ's ratio crosses 1 between f = 6 and 8; by f_κ = 12 — bench3's own band-entry dose — evaporation is already suppressed 20%. The knob family whose whole motivation is extra interface area produces, at the operating point, an interface that evaporates less.

The mechanism ranking is the REVERSE of the calibration ranking. f_κ moves a real transport coefficient and is the only one ever correct on Ṁ; f_A is in-solve but trades the Ṁ-channel against the θ-channel; f_mix is a scalar on the integrated answer and wins §2 precisely because it is unconstrained by the physics it represents. Reporting either ranking alone is misleading — see FINDINGS §10.

The experiment this implies is now fully designed: F_AREA_PLAN.md. An f_area knob applying f_κ and f_A simultaneously with one shared constant — which in the thin-layer limit is the exact 1-D representation of multiplying interface area by f (the layer's T-profile is invariant while every flux, Ṁ included, scales by exactly f). Pre-registered predictions: band entries ≈ 3.6/5.0/7.3 with spread ≈ 2.1×, and Ṁ rising with dose — the unique area signature no shipped knob shows. 0 of 174 arms set more than one knob, so this is entirely unmeasured — single-knob was enforced by construction for clean attribution. Design: offline screen (A0, free) then one 514-arm bench8 submission (fine 24-dose ladder + matched-dose single-knob margins + band configs).

11. What the result means

The deliverable — the three-way table this program had been missing — is §2. Per gate G5 both Θcum variants and the frozen-no-root share sit beside every band-setting number in bench7_analysis.csv. The pre-registered decision tree had three branches; the measurement landed on the third.

f_κ has the largest spread → it closes as a single-constant calibration knob. This time on a measurement — ≥16×, and it does not reach the band at all on the two diffuse benches — rather than on the falsified El-Badry-sign argument that §23 deleted. That correction stands either way: it was about honesty, never about promoting f_κ.

But the mechanism axis reverses the order (§3), and that is the finding that matters. f_mix wins the calibration because it is a scalar on the integrated answer, unconstrained by the structure it is meant to represent. f_κ loses the calibration while being the only knob ever correct on mass loading. Neither ranking is publishable alone.

What actually follows. The pre-registered TERMINAL stop — if no knob holds one constant across the band to the agreed factor, the single-constant program stops rather than being re-scoped into a fitted f(n) — is live: the best measured spread is f_A's 2.71× (solved rows, §3), from a knob whose mechanism sign is wrong on Ṁ. The discriminator was the f_area experiment of §4 — one shared constant across f_κ and f_A, pre-registered in F_AREA_PLAN.md with falsifiable predictions and a TERMINAL clause of its own. It was the one test that could satisfy both axes at once, and 2026-08-03 its free offline screen refuted it (GA0 failed; box in §4): the combined knob reproduces f_κ alone on Ṁ, so no shipped-knob combination is area-faithful and the zero-code route is closed. f_area's own TERMINAL clause is not triggered (it is defined on the full-run reads PA1/PA3, which never ran); the parent single-constant TERMINAL stop above is what remains live, alongside one SC-1 proposal — carry the area factor on the evaporative flux itself, which needs a derived truncation scale first.

Still soft, and stated as such

  • f_A's bench1 entry is a bound, not a point — (64, 74.8], so spread ≤ 5.39×. The pre-registered 74.8 is its correct upper end, so nothing published on the f_A side was wrong; it was unconverged and stated as if converged.
  • pl2_steep's firing-window left edge is unmeasured (f_κ = 5, 6, 7 all truncated). The non-overlap with simple_cluster holds regardless, so P3 stands.
  • 21/294 arms truncated, 12 of them diagnostic arms. Every band-entry number carries its bracket's truncated count in bench7_analysis.csv.
